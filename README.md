# todoapp-github-flow-tutorial

Todo アプリを題材にして、GitHub Flow を練習するためのチュートリアル用リポジトリです。

## 目的

- Issue を作成する
- ブランチを切って作業する
- Pull Request を作成する
- レビューや修正を経てマージする
- 小さなアプリ開発を通じて GitHub Flow に慣れる

## 想定する流れ

1. 作業内容を Issue として作成する
2. Issue に対応するブランチを作成する
3. Todo アプリに小さな変更を加える
4. Pull Request を作成する
5. 差分を確認してマージする

## メモ

このリポジトリは、完成度の高い Todo アプリを作ることよりも、GitHub Flow の一連の流れを体験することを目的とします。

GitHub Flow そのものの反復練習は `github-flow-sandbox`、Todo アプリを題材にした実践練習はこのリポジトリ、という位置づけです。
